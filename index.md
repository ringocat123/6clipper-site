# GTA Clipper

GTA Clipper is a personal, single-user desktop tool. It finds highlight moments in live gameplay streams, prepares short clips, and, after the owner manually approves each one, uploads them to the owner's own YouTube channel using YouTube API Services (youtube.upload scope).

This tool uses YouTube API Services.
