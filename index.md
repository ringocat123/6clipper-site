6clipper
6clipper is a personal, single-user desktop tool. It finds highlight moments in live gameplay streams, prepares short clips, and, after the owner manually approves each one, uploads them to the owner’s own YouTube channel using the YouTube Data API (youtube.upload scope). Contact: tsmangocatt@gmail.com

Privacy Policy
This tool is used only by its owner. It does not collect, store, or share personal data from any other user. Its YouTube access is limited to uploading videos to the owner’s own channel. OAuth tokens are stored only on the owner’s computer. The tool uses YouTube API Services, so use of it is also subject to the Google Privacy Policy and the YouTube Terms of Service. The owner’s access can be revoked at any time at https://myaccount.google.com/permissions.
