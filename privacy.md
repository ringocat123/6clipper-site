# Privacy Policy

This tool is used only by its owner and is not offered to the public.

## YouTube API Services
This tool uses YouTube API Services. By using it, you agree to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms). Google's handling of data is described in the [Google Privacy Policy](https://policies.google.com/privacy).

## Data the tool accesses and stores
- From YouTube/Google: only permission to upload videos to the owner's own channel (youtube.upload scope). The tool does not read other users' data, channel analytics, or subscriptions.
- The OAuth token is stored only on the owner's computer.
- From Twitch: public chat activity is counted to detect spikes. The tool stores timestamps and counts, not chat message content or usernames.

## Sharing
No data is sold, shared, or disclosed to third parties.

## Deletion and revocation
Access can be revoked at any time at https://myaccount.google.com/permissions. The owner can delete the locally stored token file at any time, which removes all stored YouTube authorization. Contact tsmangocatt@gmail.com with any request.
